# RALCA - Rescue Agency Locator and Co-ordination Application 🛰️

Welcome to the official repository for **RALCA** (Rescue Agency Location & Crisis Analytics), an enterprise-grade disaster management dashboard developed by **Gokul R** from **Rathinam Technical Campus** for the YUDHISTRA 2026.

## Project Overview 🚨
**RALCA** is designed to provide real-time tactical coordination during emergency crises. It bridges the gap between field personnel, emergency dispatchers, and rescue teams using live hardware telemetry, automated emergency routing, and AI-driven risk analytics.

* **Developer:** Gokul R (ECE Department, Rathinam Technical Campus)
* **Application Name:** RALCA (Rescue Agency Location App)
* **Target Location Focus:** Coimbatore, Tamil Nadu, India
* **Live Dashboard Application:** https://rgokulgokul2007-lgtm.github.io/RALCA/

## Core Features 🛠️
* **Live GPS Telemetry Tracking:** Real-time synchronization of critical incident coordinates.
* **Automated Emergency Routing:** Advanced mathematical distance calculations to immediately locate and contact the absolute closest rescue agency (e.g., Coimbatore response units).
* **AI Risk & Deployment Analytics:** Dynamic command center recommendations for rapid dispatch.
